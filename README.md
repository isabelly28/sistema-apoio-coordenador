# Sistema de Apoio ao Coordenador

Protótipo web acadêmico para facilitar a consulta de dúvidas frequentes dos alunos e apoiar o coordenador acadêmico.

## Como executar
1. Abra o arquivo `index.html` em um navegador moderno.
2. Não é necessária instalação de dependências ou servidor para testar localmente.

## Funcionalidades demonstrativas
- Busca por palavras nas perguntas e respostas.
- Visualização das respostas completas.
- Login demonstrativo para acessar a área do coordenador.
- Painel administrativo.
- Cadastro, edição, filtro e exclusão de perguntas.
- Persistência local usando `localStorage`.

## Login de demonstração

- Senha: `123456`

## Tecnologias
HTML, CSS e JavaScript em um arquivo principal (`index.html`).

## Limitações
Este é um protótipo front-end para fins acadêmicos. O login não oferece autenticação segura e os dados são salvos apenas no navegador atual. Não há backend nem banco de dados compartilhado.
